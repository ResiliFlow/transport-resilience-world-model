Help & data notes

This workspace displays a separately supplied, compatible road-safety data bundle. No research data or saved forecasts are included in this source release.

Explore and compare

Choose an available period and outcome, then select View results. The chart limit changes the displayed ranking, not the calculation population. Select a road to inspect its results.

Read results carefully

Deaths and serious injuries count people. Crash baselines count events. Probabilities are not accuracy percentages. Individual prediction intervals must not be added into a regional interval. Definitions, periods and assumptions must be documented by the data provider.

Prediction checks

Historical checks compare saved predictions with recorded outcomes. Average error is a mean absolute difference; probability error is a Brier score. Small groups can have unstable results.

SPF and CMF

The SPF panel shows a supplied crash baseline. A CMF provides a conditional reference estimate for a safety measure, not a verified local benefit. Check the source evidence, assumptions and site suitability before use.

Data rights

Supply only authorised data and retain its required licence and attribution notices. Opening this workspace does not fit or retrain a model.
