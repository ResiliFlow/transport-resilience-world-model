Connect Google imagery

Enter only the restricted Google key used for Maps, Places and the current Street View image. Standard road detection works without OpenAI. Optional OpenAI verification can be enabled later from the analysis panel.

Required APIs: Maps JavaScript API, Places API (New) and Street View Static API. Recommended referrers: http://127.0.0.1:8005/* and http://localhost:8005/*.

OPTIONAL ACCURACY ENHANCEMENT

Improve this view with OpenAI

Use your own OpenAI key only when you want an additional visual check of road, kerb and footpath issues. The key is held only in this perception tab's memory and is never shared with Platform Assistant.

Closing or refreshing this tab clears the key. Invalid, unavailable or quota-limited enhancement cannot disable local inference or any other platform workspace.
